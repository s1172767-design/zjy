02 PROJECT CONTEXT

当养老需求加速增长，
传统训练模式亟需改变。

人才是智慧养老落地的关键。我们希望用可重复、可反馈、可评估的训练方式，弥合课堂知识与真实照护场景之间的差距。

WHY NOW 我们需要怎样的养老护理人才？
更复合 护理 + 沟通 + 数字素养
更安全 低风险地练习高风险场景
更个性 基于表现持续调整训练

随着高龄、失能和失智老人数量增加，养老服务需要从基础生活照料扩展到慢病管理、心理支持、应急处置和数字健康管理等多维能力。

背景说明 · 课程项目研究摘要

传统培训以课堂讲授和视频学习为主，真实高风险场景难以反复演练；统一进度的课程也很难覆盖学员在沟通、应急和数字技能上的差异。

  • 实践机会受场地、人员与安全风险限制
  • 错误操作往往缺少即时、具体的反馈
  • 软技能和复杂情绪应对难以量化评估

AI 让虚拟老人和智能导师具备动态情境反馈能力，VR 则提供安全、可重复、可观察的沉浸式操作环境。二者连接教学、练习与评估，形成完整训练闭环。

本项目为功能原型设计，不连接商业 AI API 或真实 VR 硬件

    从课程构想到真实试点，
    分阶段推动落地。

    以“课程—场景—平台—评估”为核心，联动养老机构、职业院校与技术伙伴，稳步验证和迭代培训体系。

    完成培训平台原型、五大课程框架、AI 对话脚本与三类 VR 训练场景设计，建立能力评估指标体系。

    课程共建原型开发场景脚本

    与养老机构合作招募学员，以小组方式开展基础培训、VR 情景练习与前后能力测评，记录使用体验与教学效果。

    机构试点小班培训效果测量

    根据学员反馈、教师评价与任务数据优化对话脚本、VR 场景难度和评估反馈；补充适老化与隐私伦理内容。

    反馈研究内容优化安全审查

    形成可复制的课程与培训服务方案，逐步推广至养老机构和职业培训机构，建立持续更新的课程资源库。
